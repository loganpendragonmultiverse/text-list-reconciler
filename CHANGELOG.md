# Changelog

## 1.1.0 - 2026-10-15

- Add bounded CSV parsing, explicit column/header selection and a cancellable local preview.
- Preserve quoted multiline cells as individual items using an explicit editable CSV input mode.
- Prefix formula-like cells in CSV report exports while preserving comparison values.


## 1.0.0 - 2026-07-18

- Added local text and file-based list comparison.
- Added explicit normalization controls, cautious near-match suggestions, duplicate reporting, and source-line preservation.
- Added filterable result groups and CSV export.
- Added responsive and keyboard-accessible browser interface.
